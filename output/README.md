This directory holds simulation output files generated by the scripts in `code/`,
organized by study (matching the `code/` and `scripts/` layout).

- `binary/` — Binary simulation study (16x16, 32x32)
  - `*.rds` — Per-scenario aggregated results
  - `figures/` — Simulation study figures
- `gaussian/` — Gaussian simulation study
  - `*.rds` — Per-scenario aggregated results
  - `figures/` — Simulation study figures
- `disorder/` — Columbus physical disorder application
  - `cv_summary.csv` — Cross-validation results
  - `figures/` — Application analysis figures
